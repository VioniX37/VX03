# Dashboard

Next.js dashboard for the VioniX Sovereign Optimization Engine. See the [main README](../README.md).

```bash
npm install
npm run dev        # http://localhost:3000, expects the API on http://localhost:8000
```

Set `NEXT_PUBLIC_API_BASE` to point at a different API address. To start the API and the dashboard
together, run `python run_demo.py` from the repository root.
