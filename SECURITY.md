## Reporting a Vulnerability

The VioniX engineering team takes the numerical security, correctness, and integrity of the Sovereign Mathematical Optimization Engine seriously.

If you identify a security vulnerability, numerical attack vector (e.g., adversarial floating-point perturbation that circumvents trust verification), or dependency vulnerability:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately to the maintainers via email at:
   **`security@vionix.ai`** (or through GitHub's private vulnerability reporting feature).
3. Include the following details in your report:
   - A description of the issue and potential impact.
   - Minimal reproduction code (e.g., a sample `.mps` or `.lp` file).
   - Expected behavior vs. observed vulnerability.
   - Any proposed remediations.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate and publish an advisory.
